# 规范增量：admin-ui-sidebar

## 新增需求

### 需求：侧边栏折叠展开

#### 场景：点击折叠按钮收起侧边栏
- **WHEN** 用户在侧边栏展开状态下点击折叠按钮
- **THEN** 侧边栏宽度收窄为 64px（仅图标宽度），所有导航项 label 文字、分组标题、Logo 文字、footer 文字隐藏，主内容区左边距同步收窄为 64px

#### 场景：收起状态下点击导航图标
- **WHEN** 侧边栏处于收起状态，用户点击某个导航图标按钮
- **THEN** 页面正确切换到该图标对应的 Tab/视图，行为与展开态完全一致

#### 场景：再次点击展开侧边栏
- **WHEN** 用户在收起状态下点击展开按钮
- **THEN** 侧边栏恢复原宽度 232px，所有文字/label 重新显示，主内容区左边距同步恢复为 232px

#### 场景：刷新页面保持折叠状态
- **WHEN** 用户已将侧边栏设置为收起状态，随后刷新浏览器页面
- **THEN** 侧边栏保持收起状态（从 localStorage 读取上次状态）

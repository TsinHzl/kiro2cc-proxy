# 规范增量：admin-ui

## 新增需求

### 需求：每日统计页面 Credits 趋势图

`DailyStatsPage` 顶部须展示最近两周（14 个自然日，含今天）的 credits 用量趋势图，数据来源于已加载的 `useDailyUsage()` 结果，不发起额外请求。

#### 场景：打开每日统计页面且存在用量数据

- **WHEN** 用户打开每日统计页面，`useDailyUsage()` 返回非空数据
- **THEN** 标题行下方、表格上方展示一个折线 + 面积填充趋势图，横轴为最近 14 个自然日（按日期升序从左到右排列），纵轴为对应日期的 `totalCredits`

#### 场景：横轴覆盖最近 14 个自然日

- **WHEN** `useDailyUsage()` 返回的数据中，某个属于最近 14 个自然日范围内的日期缺失（当天无任何请求）
- **THEN** 该日期在图表横轴上仍占据对应位置，其 credits 值按 0 处理，曲线保持连续不中断

#### 场景：时间基准与后端日期字段保持一致

- **WHEN** 组件计算"最近 14 个自然日"序列
- **THEN** "今天"取当前 UTC 日历日（与 `DailySummary.date` 字段的 UTC 语义一致），序列生成与日期匹配全程使用 UTC 日期字符串运算，不经过浏览器本地时区转换；在任意浏览器本地时区下，横轴日期序列与 `data` 中日期的匹配结果一致，不出现整体错位一天的情况

#### 场景：数据点上方展示数值标签

- **WHEN** 趋势图渲染完成
- **THEN** 每个数据点正上方展示该日 `totalCredits` 的具体数值（保留与表格一致的精度或合理舍入），不遮挡相邻数据点标签

#### 场景：图表视觉呈现要素

- **WHEN** 趋势图渲染完成且至少存在一个数据点
- **THEN** 图表须同时包含以下视觉元素：标题文本、y 轴网格线（含刻度数值）、折线下方的渐变面积填充、折线上每个数据点的圆点标记、x 轴日期标签、标识"credits 用量"的图例文本——缺少其中任一元素视为未达成本场景

#### 场景：近 14 天用量全部为 0

- **WHEN** 最近 14 个自然日的 `totalCredits` 全部为 0（或 `useDailyUsage()` 数据为空数组）
- **THEN** 图表仍正常渲染为一条贴底水平线（或展示空状态提示），y 轴网格线不因除零导致渲染异常

#### 场景：数据加载中

- **WHEN** `useDailyUsage()` 处于 `isLoading` 状态
- **THEN** 趋势图区域不渲染（与现有表格的 loading 占位逻辑保持一致，不重复展示两套 loading 提示）

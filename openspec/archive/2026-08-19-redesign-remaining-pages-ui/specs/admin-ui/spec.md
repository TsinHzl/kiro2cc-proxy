# 规范增量：admin-ui 剩余页面按设计稿改版

## 新增需求

### 需求：统一页头组件

#### 场景：任意页面渲染页头
- **WHEN** 12 个页面中任意一页渲染
- **THEN** 页头结构为「面包屑（11px，末级 `font-medium text-ink-2`）→ 19px `font-semibold` 标题 → 同基线 11.5px 副标题 → 右侧动作区」
- **AND** 面包屑容器标 `aria-hidden="true"`，避免读屏与 h1 连读同一文案

#### 场景：详情页需要返回上级
- **WHEN** 页面为 B 组详情页（账号详情 / API Key 详情 / 每日明细 / 限流日志 / 失败日志）
- **THEN** 页头左侧渲染返回按钮，`aria-label` 为「返回」的 i18n 文案
- **AND** 面包屑为三级（如「主要 / 账号管理 / #003 调用记录」）

#### 场景：账号管理页页头迁移到共享组件
- **WHEN** 账号管理页渲染
- **THEN** 视觉输出与迁移前完全一致（面包屑「系统 / 账号管理」、标题「账号管理」、副标题「管理账号池、额度与限流策略」、右侧 30s 自动刷新标签 + 文档入口）

### 需求：API Keys 页表格化改版

#### 场景：页面加载完成
- **WHEN** API Keys 页数据加载完成
- **THEN** 依次渲染：`.conn` 连接卡 → 4 张指标卡 → 操作条 → 工具条 → 表格面板 → 分页器

#### 场景：连接卡展示接入信息
- **WHEN** `.conn` 连接卡渲染
- **THEN** 左区显示服务地址，取值为 `window.location.origin` + `/v1`，`https://` 与 `/v1` 用弱化色
- **AND** 中区显示兼容协议两枚 `.plan` 徽章（Anthropic Messages / OpenAI Chat）
- **AND** 右区为「复制地址」按钮与「在新窗口打开」图标按钮

#### 场景：表格列渲染（10 列，列数与设计稿一致，降级发生在单元格内）
- **WHEN** 表格渲染一行 Key
- **THEN** 列依次为：复选框 / 名称 / KEY（掩码 + 复制）/ 状态 / 绑定账号 / 消费上限 / 请求数 / 实时 RPM / 启用时间 / 操作
- **AND** 列数与设计稿 `option-a-console.html:1190-1207` 的 10 列一致，无列被删除；差异仅为 5 个列头文案按 proposal 降级表改名（权限范围→绑定账号、日配额→消费上限、请求·失败→请求数、RPM 上限→实时 RPM、最后使用→启用时间）
- **AND** 「绑定账号」在 `boundCredentialIds` 为空或未定义时显示「全部账号」
- **AND** 「消费上限」在 `spendingLimit === null` 时显示「不限」，否则显示数值 + `limitUnit` 单位
- **AND** 「启用时间」取 `activatedAt ?? createdAt`

#### 场景：Key 已停用
- **WHEN** `enabled === false`
- **THEN** 状态列显示灰色 `.tag off` 徽章
- **AND** 该行除操作列外整体降权（`[&>td:not(:last-child)]:opacity-[.55]`），操作列保持不变灰

#### 场景：Key 即将到期
- **WHEN** `expiresAt` 非 null 且距今 ≤ 7 天
- **THEN** 状态列在启用徽章右侧追加 `.tag warn` 到期提示徽章

#### 场景：现有能力保留
- **WHEN** 改版完成
- **THEN** 改版前 `api-keys-panel.tsx` 的全部交互能力均可达：生成新 Key、编辑 Key、删除 Key、启停切换、显示 / 隐藏完整 Key、复制 Key、绑定账号、查看用量详情、清除已停用

### 需求：每日统计页改版

#### 场景：4 张指标卡渲染
- **WHEN** 区间数据加载完成
- **THEN** 指标卡依次为：区间总用量（含对比上一区间的 `.delta`）/ 峰值日 / 有消耗天数（含 `.m-aside` 环形图）/ 日均（有消耗日）

#### 场景：对比上一区间
- **WHEN** 计算区间环比
- **THEN** 上升渲染 `.delta up`（绿）、下降渲染 `.delta dn`（红）、持平渲染 `.delta flat`（灰「—」）
- **AND** 上一区间总量为 0 时不渲染 `.delta`（避免除零得出无意义百分比）

#### 场景：折线图正常渲染
- **WHEN** 区间内数据点数 ≥ 2
- **THEN** 渲染面积 `<path>`（渐变填充）+ 折线 `<path>`（`vector-effect="non-scaling-stroke"`）
- **AND** 消耗 > 0 的日期渲染数据点，峰值点额外加 `.is-peak` 样式与数值标注
- **AND** Y 轴渲染 4 条刻度线与刻度值，X 轴渲染全部日期标签，峰值日标签高亮

#### 场景：折线图数据点不足
- **WHEN** 区间内数据点数 < 2
- **THEN** 不渲染折线与面积路径，仅渲染已有数据点（若有）与坐标轴
- **AND** 图表区域显示空状态文案，不出现 `NaN` 或退化路径

#### 场景：区间内全部日期消耗为 0
- **WHEN** 区间内所有 `totalCredits` 均为 0
- **THEN** Y 轴上界取 1，折线贴底渲染
- **AND** 不渲染峰值标注
- **AND** 「连续零消耗」区间带覆盖整个绘图区

#### 场景：表格列渲染（降级后 4 列）
- **WHEN** 表格渲染一行日期
- **THEN** 列依次为：日期 / 星期（客户端由 `date` 推导）/ 积分消耗（含 `.bar` 占比条与占区间百分比）/ 请求数
- **AND** 点击行跳转到该日期的每日明细页

#### 场景：区间内缺失日期
- **WHEN** 区间内某个日期在 `useDailyUsage()` 返回数据中缺失（当天无任何请求）
- **THEN** 该日期在图表横轴上仍占据对应位置，其 credits 按 0 处理，曲线保持连续不中断

#### 场景：图表视觉要素清单
- **WHEN** 图表渲染完成且至少存在 1 个数据点
- **THEN** 须同时包含：Y 轴网格线（含刻度数值）/ 折线下方渐变面积填充 / 数据点圆点标记 / X 轴日期标签 / 图例 —— 缺少任一视为未达成

### 需求：支持模型页改版

#### 场景：4 张指标卡渲染
- **WHEN** 模型清单加载完成
- **THEN** 指标卡依次为：可用模型数 / 模型家族数 / 倍率数据覆盖 / 费率倍率区间
- **AND** 「费率倍率区间」在全部模型 `rate_multiplier` 均为 null 时显示「—」而非 `NaN`

#### 场景：家族分组表格
- **WHEN** 表格渲染
- **THEN** 模型按家族分组，每组前插入一行 `.grp` 分组行（家族名 + 数量 + 该组倍率区间）
- **AND** 家族由 `ModelItem.id` 前缀客户端推导，无法归类的模型归入「其他」组

#### 场景：表格列渲染（降级后 7 列）
- **WHEN** 表格渲染一行模型
- **THEN** 列依次为：序号 / 模型 ID（`display_name` 作二级文案）/ 类型 / 最大输出 / 费率倍率（`.mult-bar` 条 + 数值）/ 状态 / 操作
- **AND** `rate_multiplier` 为 null 或 undefined 时倍率列显示「—」，不渲染 `.mult-bar`
- **AND** `.mult-bar` 宽度按该模型倍率占全清单最大倍率的比例计算；最大倍率为 0 时全部渲染为 0 宽

#### 场景：倍率高低语义色
- **WHEN** 渲染 `.mult-bar` 与倍率数值
- **THEN** 倍率 ≥ 全清单最大倍率时用 warn 色，其余用 brand 色

### 需求：实时日志页改版

#### 场景：4 张指标卡渲染
- **WHEN** 日志流已建立连接
- **THEN** 指标卡依次为：缓冲区行数（当前 / 上限）/ 近 1 小时 ERROR 数（danger 色）/ 近 1 小时 WARN 数（warn 色）/ 已观测级别分布
- **AND** 全部数值由客户端持有的缓冲区统计得出，不请求后端

#### 场景：级别分段筛选
- **WHEN** `.logbar` 渲染级别分段器
- **THEN** 分段项为「全部 / ERROR / WARN / INFO / DEBUG」，每项带对应语义色 pip 与实时计数
- **AND** 选中某级别后 `.logstream` 仅渲染该级别行

#### 场景：日志行渲染
- **WHEN** `.logstream` 渲染一行日志
- **THEN** 行结构为「时间戳（等宽弱化）/ 级别徽章 `.lv` / target（等宽弱化）/ 消息」
- **AND** 级别为 ERROR 时整行加 `.is-err` 左侧色条与消息强调色

#### 场景：折叠重复开关
- **WHEN** 「折叠重复」开关为开
- **THEN** 连续出现的 target + message 完全相同的行合并为一行，并显示重复次数
- **AND** `.panel-foot` 显示「显示 N / M 行」

#### 场景：客户端动作
- **WHEN** 点击「下载日志」
- **THEN** 将当前缓冲区内容以 Blob 形式触发下载，不请求后端
- **WHEN** 点击「清空缓冲」
- **THEN** 清空客户端缓冲区，不请求后端，指标卡计数同步归零

#### 场景：连接断开
- **WHEN** SSE 连接断开
- **THEN** 页头状态徽章由 `.tag ok`「已连接 · 实时」变为 `.tag off`（或 warn）并显示断开文案

### 需求：更新日志页时间线改版

#### 场景：左侧版本索引
- **WHEN** 更新日志加载完成
- **THEN** 左侧渲染 sticky 版本索引，最近 6 个版本逐条列出（版本号 + 日期），当前版本高亮
- **AND** 更早版本按 minor 版本聚合为归档项（如「v2.6.x · 6 条」）
- **AND** 点击索引项滚动到对应时间线节点

#### 场景：右侧时间线节点
- **WHEN** 渲染一个版本节点
- **THEN** 节点头部为「版本号 + 最新版本徽章（仅 `is_latest` 时）+ 日期 · N 项变更」
- **AND** 节点主体按 `groups` 分区，每区有带图标的分类标题
- **AND** 分类标题的语义色按组标题映射：新增 → ok、修复 → brand、变更 → warn，未匹配的组标题用中性色

#### 场景：条目内的代码片段
- **WHEN** 条目文案中含反引号包裹的代码
- **THEN** 渲染为 `.code-bg` 背景的等宽内联代码
- **AND** 无反引号时按纯文本渲染，不做其他解析

#### 场景：语言切换
- **WHEN** 界面语言为 en
- **THEN** 版本节点的组标题取 `title_en`、条目取 `items[].en`，无中文残留

### 需求：设置页分区式改版

#### 场景：分区渲染
- **WHEN** 设置页渲染
- **THEN** 渲染「服务」「认证与安全」「界面」三个分区，每个分区为 `.set-cap` 标题 + `.set-card` 卡片
- **AND** 每行为 `.set-row`：左列「`.set-k` 键名 + `.set-d` 说明」，右列 `.set-c` 控件

#### 场景：有后端支撑的配置项
- **WHEN** 渲染配置项
- **THEN** 仅渲染以下 5 项：管理后台密码（认证与安全）/ 账号选择策略（服务）/ 界面语言（界面）/ 主题（界面）/ 侧栏默认收起（界面）
- **AND** 管理后台密码默认掩码展示，点击「修改」进入编辑态

#### 场景：设计稿中不渲染的项（预期行为，非缺失）
- **WHEN** 对照设计稿 `option-a-console.html:2281-2536`
- **THEN** 以下项**不渲染**，因后端无对应配置接口：监听地址与端口、对外基础 URL、上游请求超时、日志级别、日志缓冲区大小、额度刷新间隔、限流冷却时长、额度告警阈值、失败自动重试、额度耗尽自动停用、强制 API Key 鉴权、全局速率限制、IP 允许列表、日志脱敏、记录请求体、时区、默认落地页
- **AND** 「账号池与调度」与「危险区」两个分区标题整体不渲染
- **AND** 页头的「导出配置 / 放弃更改 / 保存并重载」三个动作按钮不渲染（现有配置项均为即时生效）

#### 场景：主题分段器
- **WHEN** 渲染主题控件
- **THEN** 为 `.seg` 分段器，选项为「浅色 / 深色」两档，与侧栏页脚的主题切换按钮状态同步
- **AND** 不渲染「跟随系统」档（现有 `useTheme` 无该状态）

### 需求：B 组无稿页面模式对齐

#### 场景：账号详情 / API Key 详情 / 每日明细页
- **WHEN** 页面渲染
- **THEN** 使用带 `onBack` 的统一页头 + `.metric` 指标卡（若该页有汇总数据）+ `.panel` + `.tscroll` 表格 + `.panel-foot`
- **AND** 不引入任何 A 组未使用过的新组件类

#### 场景：限流日志 / 失败日志页
- **WHEN** 页面渲染
- **THEN** 使用带 `onBack` 的三级面包屑页头 + `.panel` + `.tscroll` 表格
- **AND** 时间戳列用等宽字体，错误消息列超长时截断并挂 `title`

#### 场景：登录页
- **WHEN** 登录页渲染
- **THEN** 使用新令牌配色与 `.field` 风格输入框、`.btn-primary` 提交按钮
- **AND** 不使用页头组件（登录页无侧栏与面包屑）

#### 场景：空状态与加载态
- **WHEN** B 组任意页面数据为空或加载中
- **THEN** 渲染与 A 组一致的空状态 / 加载态形态，不出现布局塌陷

# 规范增量：admin-ui

## 新增需求

### 需求：设计令牌体系

#### 场景：浅色主题令牌生效
- **WHEN** 浏览器 `<html>` 上不含 `.dark` 类
- **THEN** 页面背景为 `#F6F7F8`、卡片表面为 `#FFFFFF`、分隔线为 `#E6E8EA`、主文字为 `#0F1113`、品牌强调色为 `#0D7A6F`

#### 场景：深色主题令牌生效
- **WHEN** `<html>` 含 `.dark` 类
- **THEN** 页面背景为 `#0C0D0F`、卡片表面为 `#15171A`、侧栏为 `#111316`、分隔线为 `#24282D`、主文字为 `#ECEEF0`、品牌强调色为 `#2BB8A6`

#### 场景：主题切换持久化不变
- **WHEN** 用户点击侧栏页脚主题按钮
- **THEN** `<html>` 的 `.dark` 类切换，`localStorage['admin-ui-theme']` 写入 `'dark'` 或 `'light'`，刷新后保持该主题（沿用现有机制，不改为 `data-theme`）

#### 场景：其他页面继承新令牌
- **WHEN** 用户切换到 API Keys / 每日统计 / 设置 / 日志 / 模型 / 更新日志任一页面
- **THEN** 这些页面的背景、卡片、边框、主按钮颜色随新令牌变化，且不出现文字与背景对比度不足导致不可读的区域

### 需求：侧栏外壳

#### 场景：展开态结构
- **WHEN** 侧栏处于展开态（宽 232px）
- **THEN** 自上而下依次渲染：品牌区（渐变方块 + `Kiro2CC` + `Proxy Console` + 收起按钮）、分组标题「主要」+ 4 个导航项、分组标题「系统」+ 3 个导航项、登录身份区（头像 + `admin` + 角色 + 退出按钮）、页脚（运行状态点 + 版本号 + 主题按钮）

#### 场景：导航激活态
- **WHEN** 当前页签为账号管理
- **THEN** 「账号管理」导航项背景为 `--brand-soft`、文字为 `--brand`、左侧显示 2.5px 品牌色竖条，其余导航项为默认前景色

#### 场景：导航计数
- **WHEN** 账号列表已加载且包含 N 个账号
- **THEN** 「账号管理」导航项右侧显示数字 N
- **WHEN** 某导航项对应的数据尚未加载
- **THEN** 该项右侧不渲染任何数字（不显示 `0`）

#### 场景：收起态
- **WHEN** 用户点击收起按钮
- **THEN** 侧栏宽度变为 64px，品牌文字、导航文案、计数、身份文字、版本号隐藏，仅保留图标居中；分组标题降级为一条水平分隔线；`localStorage['sidebar-collapsed']` 记录状态

#### 场景：收起态提示
- **WHEN** 侧栏处于收起态且鼠标悬停在某导航图标上
- **THEN** 图标右侧浮出该项名称的 tooltip

#### 场景：退出登录
- **WHEN** 用户点击身份区的退出按钮
- **THEN** 执行与当前实现完全一致的登出流程（清除 token 并返回登录页）

#### 场景：页脚状态点
- **WHEN** 服务信息查询成功
- **THEN** 页脚显示绿色状态点 + 「运行中」+ 版本号
- **WHEN** 服务信息查询失败或加载中
- **THEN** 状态点降级为灰色且不显示版本号

### 需求：页头与指标条

#### 场景：页头结构
- **WHEN** 进入账号管理页
- **THEN** 页头显示面包屑「主要 / 账号管理」、标题「账号管理」、副标题「管理账号池、额度与限流策略」、右侧显示带脉冲点的「自动刷新 30s」标签与「文档」按钮

#### 场景：指标条 ① 账号池
- **WHEN** 账号列表已加载
- **THEN** 显示账号总数为主值，脚注依次显示「N 启用 · N 禁用 · N 项异常」，其中异常数 = `warning + degraded + unhealthy` 之和；异常数 > 0 时该片段以 danger 色显示

#### 场景：指标条 ② 全局剩余积分（已查询）
- **WHEN** 至少一个账号已查询到余额
- **THEN** 主值显示已查询账号剩余额度之和（保留 1 位小数），脚注显示「已覆盖 N / M 个账号」
- **AND** 因缺少历史基线，不渲染环比 delta 徽章

#### 场景：指标条 ② 全局剩余积分（未查询）
- **WHEN** 没有任何账号查询过余额
- **THEN** 主值显示 `—`，脚注提示用户点击「查询信息」

#### 场景：指标条 ③ 平均剩余百分比
- **WHEN** 存在已查询余额的启用账号
- **THEN** 主值为这些账号剩余百分比的算术平均（取整），右侧环形图按该百分比着色（≥60% 用 ok 色、30–60% 用 warn 色、<30% 用 danger 色），脚注显示剩余百分比最低的账号名与其百分比
- **WHEN** 不存在已查询余额的启用账号
- **THEN** 主值显示 `—`，环形图仅渲染空轨，脚注隐藏最低账号信息

#### 场景：指标条 ④ 今日调用
- **WHEN** `useDailyUsage` 返回今日汇总
- **THEN** 主值为今日 `totalRequests`（千分位分隔），右侧渲染最近 7 天请求数 sparkline
- **WHEN** 存在昨日数据
- **THEN** 显示环比徽章（上升为 ok 色 ↑、下降为 danger 色 ↓、持平不显示）
- **WHEN** 不存在昨日数据
- **THEN** 不渲染环比徽章

#### 场景：指标条 ④ 失败读数降级
- **WHEN** 渲染今日调用脚注
- **THEN** 显示账号池累计失败数与累计失败率（`Σfail / (Σfail + Σsuccess)`），文案明确标注为「累计」而非今日；累计失败数为 0 时以次要色显示

### 需求：操作条

#### 场景：操作按钮常驻
- **WHEN** 进入账号管理页
- **THEN** 操作条从左到右显示：刷新账号列表、查询信息、竖分隔线、清除已禁用（danger 描边）、竖分隔线、Kiro Account Manager 导入、批量导入，最右侧显示主按钮「添加账号」

#### 场景：查询信息进行中
- **WHEN** 「查询信息」正在逐个查询当前页账号余额
- **THEN** 该按钮进入禁用态并显示进度文案 `N / M`，行内对应账号的额度单元格显示加载态

#### 场景：空列表时的操作条
- **WHEN** 账号列表为空
- **THEN** 「查询信息」与「清除已禁用」两个按钮不渲染（保留现有行为），其余按钮正常显示

#### 场景：无可清除账号
- **WHEN** 账号列表非空但不存在已禁用账号
- **THEN** 「清除已禁用」按钮呈禁用态并 title 提示无可清除账号（保留现有行为）

#### 场景：验活进度浮动入口
- **WHEN** 批量验活正在进行且验活进度对话框已被关闭
- **THEN** 操作条显示带旋转图标的进度按钮（文案含 `N / M`），点击可重新打开进度对话框
- **WHEN** 验活结束或进度对话框处于打开状态
- **THEN** 该按钮不渲染

### 需求：搜索与筛选

#### 场景：关键词过滤
- **WHEN** 用户在搜索框输入关键词
- **THEN** 表格仅保留昵称、邮箱或账号 ID 中（不区分大小写）包含该关键词的账号，并把当前页码重置为 1
- **AND** 不以 Profile ARN 作为匹配字段（后端仅返回 `hasProfileArn: boolean`，无 ARN 字符串）

#### 场景：⌘K 聚焦
- **WHEN** 用户按下 `⌘K`（macOS）或 `Ctrl+K`（其他平台），且当前焦点不在任何输入框内
- **THEN** 阻止浏览器默认行为并聚焦搜索框

#### 场景：清空搜索
- **WHEN** 搜索框有内容且用户点击清除按钮或清空输入
- **THEN** 恢复显示全部（当前筛选段内的）账号

#### 场景：状态分段筛选
- **WHEN** 用户点击「健康 / 异常 / 禁用 / 待验证」任一分段
- **THEN** 表格仅显示匹配该状态的账号，该分段呈选中态，页码重置为 1
- **AND** 每个分段标签上的计数始终反映**搜索过滤后**的账号集合中各状态的数量

#### 场景：筛选后无结果
- **WHEN** 搜索与筛选组合后无任何账号匹配
- **THEN** 表体显示空状态提示（说明无匹配结果并提供清除筛选入口），而非显示空白表格

#### 场景：更新时间
- **WHEN** 账号列表数据更新
- **THEN** 工具栏右侧显示「更新于 X 前」的相对时间，并随时间推移自动刷新文案

### 需求：账号表格

#### 场景：列结构
- **WHEN** 表格渲染
- **THEN** 依次呈现 10 列：全选复选框、ID、账号、状态、套餐、剩余额度、调用/失败、RPM、最后调用、操作

#### 场景：表头吸顶
- **WHEN** 用户在表体内向下滚动
- **THEN** 表头保持固定在面板顶部可见

#### 场景：账号列排序
- **WHEN** 用户点击「账号」列表头
- **THEN** 按昵称（缺失时回退到邮箱）升序排序；再次点击切换为降序；表头显示当前排序方向指示

#### 场景：剩余额度列排序
- **WHEN** 用户点击「剩余额度」列表头
- **THEN** 按剩余额度排序，未查询余额的账号恒排在末尾（无论升序或降序）

#### 场景：排序重置分页
- **WHEN** 排序键或方向发生变化
- **THEN** 当前页码重置为 1

#### 场景：账号单元格
- **WHEN** 渲染某账号行
- **THEN** 显示首字母头像（颜色由状态语义决定）、昵称（缺失时显示 `账号 #ID`）、优先级徽章 `P{priority}`、以及脱敏邮箱（单行截断，悬停显示完整值）

#### 场景：代理与 ARN 标识
- **WHEN** 账号 `hasProxy` 为真且存在 `proxyUrl`
- **THEN** 邮箱右侧显示 `PROXY` 微徽章，悬停显示完整代理地址
- **WHEN** 账号 `hasProfileArn` 为真
- **THEN** 邮箱右侧显示 `ARN` 微徽章
- **AND** 因后端不返回 ARN 字符串，该徽章不提供复制或查看具体值的操作

#### 场景：状态标签映射
- **WHEN** 账号 `disabled` 为真
- **THEN** 状态列显示灰色「已禁用」标签
- **WHEN** 账号 `healthStatus` 为 `unhealthy` 或 `degraded`
- **THEN** 显示 danger 色「异常」标签
- **WHEN** 账号 `healthStatus` 为 `warning`
- **THEN** 显示 warn 色「额度告警」标签
- **WHEN** 账号 `healthStatus` 为 `healthy` 且 `successCount` 为 0 且无余额数据
- **THEN** 显示品牌色「待验证」标签
- **WHEN** 以上均不满足
- **THEN** 显示 ok 色「健康」标签

#### 场景：额度单元格（已查询）
- **WHEN** 该账号存在余额数据
- **THEN** 显示 `剩余 / 上限` 的数值组合、剩余百分比（按 60/30 阈值着色）以及 4px 进度条

#### 场景：额度单元格（未查询）
- **WHEN** 该账号没有余额数据
- **THEN** 套餐列显示 `—`，额度列显示「尚未查询」与 `—`，进度条为空轨

#### 场景：调用与 RPM
- **WHEN** 渲染调用列
- **THEN** 显示成功次数；失败次数 > 0 时以 danger 色附加显示，等于 0 时以次要色显示
- **WHEN** 该账号当前 RPM 为 0
- **THEN** RPM 列以次要色显示 `0`

#### 场景：计数点击跳转日志
- **WHEN** 用户点击调用列中的失败次数
- **THEN** 跳转到该账号的失败日志页（等价于现有 `onViewFailureLog`）
- **WHEN** 该账号 `throttleCount` 大于 0
- **THEN** 调用列附加显示限流次数（warn 色），点击后跳转到该账号的限流日志页（等价于现有 `onViewThrottleLog`）
- **WHEN** `throttleCount` 等于 0
- **THEN** 调用列不显示限流数字（入口仍可从「更多」菜单进入）

#### 场景：禁用行降权
- **WHEN** 账号处于禁用状态
- **THEN** 整行内容降低不透明度，但行内所有操作控件仍可点击

#### 场景：行内操作
- **WHEN** 渲染操作列
- **THEN** 显示启停开关，以及额度详情、调用日志、编辑三个图标按钮和一个「更多」菜单按钮，每个图标按钮悬停显示名称提示

#### 场景：更多菜单
- **WHEN** 用户点击「更多」按钮
- **THEN** 弹出菜单依次包含「重新查询余额」、「失败日志」、「限流日志」、「重置失败计数」、「删除账号」（danger 色）
- **AND** 菜单不包含「复制 ARN」（无可复制的 ARN 字符串）

#### 场景：重置失败计数的可用条件
- **WHEN** 账号 `failureCount` 等于 0
- **THEN** 「重置失败计数」菜单项呈禁用态（与现有卡片实现的禁用条件一致）

#### 场景：删除的前置约束
- **WHEN** 账号未被禁用（`disabled === false`）
- **THEN** 「删除账号」菜单项呈禁用态，并提示需先禁用该账号（保留现有卡片实现的同一约束）
- **WHEN** 账号已被禁用且用户点击「删除账号」
- **THEN** 弹出二次确认对话框，确认后才执行删除

#### 场景：启停开关
- **WHEN** 用户切换某行开关
- **THEN** 调用现有启停接口，成功后该行状态标签与降权样式同步更新
